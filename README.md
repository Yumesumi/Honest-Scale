# Honest Scale · 心里那杆秤

> 把包装规格一键换算成「每克 / 每毫升多少钱」，买零食心里有杆秤。

在零食店、超市里，同一件商品常常有好多层包装：一箱几盒、一提几袋、大瓶还是小瓶、克重还是毫升。标签上的总价根本没法直接比较。**Honest Scale** 做的是一件很小的事——剥掉包装的迷惑，把任何东西都折算成同一个尺子下的**单位价格**，让你在三秒钟内知道到底哪个更划算。

## 它能帮你做什么

- **液体**：ml / L 自动换算，直接得到 `元 / ml`
- **固体**：g / kg 自动换算，直接得到 `元 / g`
- **多层包装**：一箱 12 盒、一提若干袋这种「包装里还有包装」也能算清楚
- **并排比价**：同时输入两个商品，谁单价更低一目了然

## 举个例子

| 商品 | 规格 | 数量 | 总价 | 单位价 |
| --- | --- | --- | --- | --- |
| 某品牌牛奶（箱装） | 250 ml / 盒 | 12 盒 | 48 元 | **0.016 元 / ml** |
| 同规格牛奶（单卖） | 500 ml / 盒 | 1 盒 | 6 元 | **0.012 元 / ml** |

看起来箱装便宜，换算成单位价后，单盒 500 ml 的其实更划算——这就是心里那杆秤存在的意义。

## 名字由来

「Honest Scale / 心里那杆秤」——每个人买东西时，心里都有一杆称量「值不值」的秤。它不直说价格、单位这些词，而是取那杆秤的意象：**诚实地衡量，明明白白地买。**
